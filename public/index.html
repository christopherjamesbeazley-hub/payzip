Add pay buttons to any website

Paste this where the button should appear, and change live-test to a product id from products.mjs:

<script src="https://payzip.netlify.app/embed.js" defer></script>
<div data-payzip="live-test" data-payzip-lang="nl"></div>

Or use a plain link: https://payzip.netlify.app/api/checkout?product=live-test&provider=stripe

This page is not listed in search engines. Order events appear in Netlify → Logs → Functions.
